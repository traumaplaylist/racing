# Canyon Clash — пакет для первого билда

Canyon Clash — рабочее название одиночной аркадной гонки с боем. Первый билд — Windows. Игрок собирает машину в гараже, выходит на три круга против пяти ботов и побеждает, если первым пересекает финиш или остаётся единственным гонщиком на трассе.

## Передача в Claude Code

1. Распакуй ZIP в корень нового проекта. Если проект уже существует, сверь его инструкции перед добавлением файлов.
2. Добавь к разговору в Claude три концепта пустынной версии из текущего чата — заезд, гараж и результаты. Промзона и снежный перевал показывают возможные следующие трассы.
3. Запусти Claude Code из корня проекта и отправь текст ниже. Claude Code использует CLAUDE.md как точку входа для инструкций проекта.

> Прочитай CLAUDE.md, AGENTS.md и TASK.md, затем связанные документы. Проверь состояние репозитория и наличие Godot. Реализуй Windows v0.1 по этапам из TASK.md, начиная с управления, камеры и круга по трассе. Заверши каждый этап рабочим результатом и продолжай до экспортируемого билда. В конце пройди ACCEPTANCE.md и укажи путь к билду, результаты проверок и конкретные блокеры, если они остались.

| Файл | Что внутри |
|---|---|
| [CONCEPT.md](CONCEPT.md) | Игровая петля, правила, контент, стартовые значения баланса |
| [TASK.md](TASK.md) | Порядок разработки и результат каждого этапа |
| [AGENTS.md](AGENTS.md) | Инструкции для разработчика, границы v0.1 и технические требования |
| [CLAUDE.md](CLAUDE.md) | Точка входа для Claude Code |
| [ACCEPTANCE.md](ACCEPTANCE.md) | Сценарии проверки билда |
| [ART_DIRECTION.md](ART_DIRECTION.md) | Камера, интерфейс и описание пяти концепт-скриншотов |

Целевой стек при старте с нуля — Godot 4.x stable, GDScript и Compatibility. Windows-билд поставляется в ZIP с запускаемым приложением. Подготовка к Steam и Android заложена в технических требованиях к первому билду.
