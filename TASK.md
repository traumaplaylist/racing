# Задача для Claude — собрать Windows v0.1

Собери офлайн-билд Canyon Clash, который можно распаковать и запустить на Windows x86-64. Следуй правилам в [CONCEPT.md](CONCEPT.md) и проверкам в [ACCEPTANCE.md](ACCEPTANCE.md). [ART_DIRECTION.md](ART_DIRECTION.md) задаёт визуальную цель. Начни с тестовой геометрии, чтобы отладить езду, камеру и бой до оформления трассы.

| Этап | Сделать | Результат этапа |
|---|---|---|
| 0. Старт | Проверить репозиторий и Godot. При старте с нуля создать проект с Windows x86-64 preset и зафиксировать точную версию движка. Добавить действия ввода | Проект открывается и запускает первую сцену |
| 1. Езда | Один автомобиль, кольцо из простой геометрии, разгон, тормоз, реверс, ручник, дрифт, барьеры, восстановление, камера и контрольные точки | Можно проехать три валидных круга, камера держит поворот в кадре |
| 2. Бой и ИИ | Добавить HP, два оружия, два бонуса, пять ботов. Боты следуют по линии, используют смещение для объезда, тормозят на дугах и стреляют вперёд по подходящим целям | Полноценный заезд с обоими способами победы и корректным поражением |
| 3. Гараж и прогресс | Две машины, выбор оружия, броня и двигатель, сохранение, результаты, Retry, пауза и выход | Полный цикл от выбора машины до применения купленного улучшения в следующем заезде |
| 4. Оформление | Пустынный каньон, цветовые силуэты машин, читаемый HUD, звуки двигателя, дрифта, выстрела, попадания и подбора | Гонка читается с игровой камеры без объяснений разработчика |
| 5. Билд | Проверить проект и Windows-экспорт, прогнать приёмку, упаковать приложение со всеми зависимыми файлами | ZIP с билдом, команда экспорта, список проверок и известных ограничений |

## Стартовая раскладка

| Действие | Клавиатура | Геймпад Xbox |
|---|---|---|
| Газ | W / ↑ | RT |
| Тормоз и реверс после остановки | S / ↓ | LT |
| Руль | A / D или ← / → | Левый стик |
| Ручник | Space | A |
| Выстрел | J | RB |
| Восстановить машину | R | Y |
| Пауза | Esc | Menu |

В меню поддержи мышь, стрелки и Enter, геймпадом — D-pad или левый стик, A для выбора, B для возврата. В гонке отсчёт стартует на «3», ход гонки и выстрелы начинаются на «Go». Экран паузы даёт продолжить, начать попытку заново или выйти в гараж.

## Что передать по завершении

- Исходники проекта, Windows preset, ZIP с приложением и инструкция запуска.
- Точную версию Godot, воспроизводимую команду экспорта и расположение шаблонов при необходимости.
- Список сценариев из ACCEPTANCE.md со статусами «прошёл», «не прошёл», «не проверен». Для производительности указать железо, разрешение и результат замера.
- Для систем, требующих ручного плейтеста, описать короткий способ воспроизвести состояние, включая победу после уничтожения соперников и выдачу награды.
