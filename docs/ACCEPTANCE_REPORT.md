# Приёмка Windows v0.1 — отчёт

Билд: `build/CanyonClash-v0.1-windows-x86_64.zip` (в репозиторий не коммитится; собирается `tools/build_windows.sh`).
Движок: Godot 4.5.1-stable, Compatibility. Дата прогона: 2026-11-11.

## Среда проверки и её ограничения

- Облачный Linux-контейнер: Intel Xeon 2.3 GHz, 4 vCPU, без GPU, без Windows, без Wine, без устройств ввода и звука.
- Windows `.exe` собран, но **на Windows не запускался**. Тот же PCK (тот же экспорт-пресет и фильтры) экспортирован
  под Linux и запущен вне редактора: release — headless без ошибок, debug — гараж отрисован под Xvfb (Mesa llvmpipe).
- Ручной ввод (клавиатура, геймпад, мышь) **не проверялся**: в среде нет устройств. Движение, бой и правила
  проверены автотестами через тот же набор команд, который получает машина игрока.
- Рендер проверен скриншотами под Xvfb/llvmpipe при 1280×720 и 1920×1080. Это программный рендер:
  кадры подходят для оценки композиции, но не для FPS.

Автотесты: `tests/sim_test.tscn` — **53 / 53 прошли**. Баланс: `tests/balance.tscn` — 12 заездов автопилота.

## Как воспроизвести вручную

- **Победа на выживание и награда.** Взять Pulse Cannon, держаться позади группы и стрелять по одной цели. Боты выбивают друг друга сами. В отладочной сборке быстрее так: `--debug-scene=results --debug-result=last_standing`.
- **Финиш бота.** Ехать в хвосте и не обгонять. Первый бот финиширует примерно через 2:45 → поражение, +50 CR. Учтите: боты, которые обходят на круг, стреляют, поэтому машину могут выбить раньше. Надёжно воспроизводится автотестом или флагом `--debug-result=rival_finished`.
- **Тайм-аут.** Ехать медленно, без завершения круга, и держаться у Repair. Через 5:00 активного времени (паузы не считаются) → +25 CR. Боты финишируют раньше, поэтому вручную состояние почти недостижимо; правило покрыто автотестом `5 min timeout`.
- **Повреждённый профиль.** Закрыть игру, испортить `%APPDATA%\Godot\app_userdata\Canyon Clash\profile.json`, запустить игру: гараж покажет «restored from backup».

## Известные ограничения и риски

1. **Баланс боя.** Автопилот, который не уворачивается, гибнет в 4 заездах из 12, обычно в первые 30–40 с. Причина: боты сзади стреляют по идущему впереди. Оружие стреляет только вперёд, а значения урона заданы CONCEPT.md, поэтому смертоносность снижена только поведением ботов: огонь с 10-й секунды, очереди с паузами, 5 с без огня по только что поражённой цели, дальность 30 м. Нужен живой плейтест.
2. **Камера.** Машина занимает ~10–12% высоты кадра на скорости (цель 12–16%). Камера отъезжает с 29 до 39 м, чтобы вираж появлялся раньше, — ART_DIRECTION это допускает. Параметры экспортированы в `race_camera.gd`.
3. **Иконка exe** — стандартная Godot: смена ресурсов exe (rcedit) недоступна при экспорте из Linux.
4. **Звук** синтезирован процедурно, двигатель озвучен только у игрока. Боты слышны через выстрелы, попадания и взрывы с затуханием по расстоянию.
5. **Концепт-скриншоты** в этот репозиторий не передавались. Визуал собран по описанию ART_DIRECTION.md.
