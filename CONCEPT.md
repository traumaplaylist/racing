# Canyon Clash — концепт v0.1

## Игровая петля

Выбрать машину и оружие → проехать три круга против пяти ботов → получить кредиты → улучшить броню или двигатель → проверить новую сборку в следующем заезде. Игрок решает на ходу, держать быструю траекторию, приблизиться к сопернику для выстрела или сместиться к бонусу. Ориентир — 2–3 минуты на чистый заезд.

## Правила заезда

- После отсчёта стартуют все шесть машин. Валидный круг требует прохода контрольных точек по порядку и пересечения финиша в правильном направлении. Позиция живых машин считается по кругам, пройденным контрольным точкам и прогрессу до следующей точки. HUD показывает текущую позицию из стартовых шести, число оставшихся соперников выводится отдельно.
- Победитель определяется по первому валидному финишу третьего круга или по единственной оставшейся в строю машине. Боты могут выбивать друг друга. Для победы на выживание достаточно остаться последним. В статистику игрока идут только выбитые им соперники.
- Если несколько терминальных событий попали в один физический тик, сначала применить весь урон, затем проверить валидные финиши живых машин по порядку пересечения, затем проверить единственного выжившего. При точном совпадении финишей использовать стабильный ID гонщика. При одновременном уничтожении всех машин — поражение без победителя.
- Уничтожение игрока завершает попытку. Первый финиш бота завершает попытку поражением, если игрок ещё в заезде. Результат фиксируется один раз. Тайм-аут в 5 минут активной гонки даёт поражение, пауза останавливает отсчёт.
- Машина уничтожается при 0 HP. Боевой урон и урон от сильных столкновений применяются и к игроку, и к ботам. Лёгкое касание барьера не отнимает HP. Сбитая машина перестаёт влиять на ход гонки после короткого визуального эффекта.
- Оба оружия направлены строго по продольной оси кузова. Игрок целится поворотом машины, в том числе в дрифте. Выстрел ограничен кулдауном, запас выстрелов бесконечен. Показывать попадание и готовность следующего выстрела.
- Бонус срабатывает один раз на первое касание подходящей машины. Repair при полном HP остаётся на трассе. Boost обновляет длительность при повторном подборе, эффекты скорости не складываются. Точки бонусов общие для игрока и ботов.
- Ручное восстановление ставит живую машину на последнюю валидную контрольную точку в направлении гонки, убирает текущую скорость и сохраняет HP, порядок точек и время гонки. Повторный Reset — через 3 с. Если место занято, искать свободное место рядом или отложить сброс. Боты пользуются тем же восстановлением при длительном застревании.

## Начальные параметры для плейтеста

| Параметр | Значение |
|---|---|
| Buggy / Bruiser | 100 / 135 HP, целевая максимальная скорость 145 / 128 км/ч |
| Blaster / Pulse Cannon | 7 HP каждые 0,22 с / 27 HP каждые 0,95 с |
| Repair / Boost | +30 HP с ограничением максимума / +20% к предельной скорости и разгону на 2 с |
| Повторное появление бонусов | 10 с после подбора |
| Награды | 120 CR за победу любым способом, 50 CR за поражение от финиша соперника, 25 CR за уничтожение игрока, отсутствие победителя или тайм-аут. Добровольный выход и рестарт — 0 CR |
| Броня | Уровни I–III, каждый переход даёт +12 HP от базового значения, эффекты уровней суммируются |
| Двигатель | Уровни I–III, каждый переход даёт +4% к базовой максимальной скорости и разгону, эффекты уровней суммируются |
| Цена улучшений | I → II — 100 CR, II → III — 200 CR по каждому параметру. Начальный баланс 0 CR |

Значения можно подстроить после плейтеста. Сохранение хранит баланс, выбранные машину и оружие и купленные уровни отдельно для каждой машины. Retry запускает тот же комплект. Новая гонка стартует с полным HP.
